# Журнал работы

## 2026-09-20 — 2026-09-21: движок и редактор построек

### Кастомный Godot 4.7.2 (double precision + C#)
- Собраны редактор и шаблоны экспорта (`precision=double module_mono_enabled=yes`), MSVC 2022.
- Первая версия падала при открытии GUI-редактора (`0xC0000005` после `EditorTheme: Generating new styles`).
  Долгая диагностика (рендерер, компилятор MSVC/MinGW, версии Godot 4.6.3/4.7.2, .NET SDK, AccessKit, целостность GodotTools)
  ничего не дала. **Причина:** `build_assemblies.py` по умолчанию собирает C#-биндинги под float
  (`--precision=single`), а движок был double. **Решение:** всегда `build_assemblies.py --precision=double`.
  Подробности и полная последовательность сборки — [01-engine-build.md](01-engine-build.md).
- Диагностические артефакты (MinGW, Godot 4.6.3, ProcDump, лишний .NET SDK, дампы) удалены.

### Проект и C#

  с `packageSourceMapping`, чтобы `Godot*` брались только из наших double-пакетов (иначе с nuget.org подтянутся float).
  Проверено по хэшу `GodotSharp.dll`. См. [02-project-setup.md](02-project-setup.md).

### Редактор построек v0.1
Реализовано по ТЗ (подробно — [03-build-editor.md](03-build-editor.md)):
1. камера WASD (+ Q/E, Shift/Ctrl, поворот по СКМ);
2. хотбар на 9 слотов, Tab — список всех блоков (12 блоков);
3. тулбар справа: Paint (цвет + палитра), Delete, Wireframe (off / overlay / only);
4. установка блоков на ПКМ (с «призраком» и контуром цели);
5. отсечение внутренних граней, жадное слияние полигонов по цвету, единый wireframe (правило «настоящего ребра»,
   не зависит от цвета и границ чанков).

Архитектурные решения: разреженные чанки 16³ с инкрементальной пересборкой; рейкаст по сетке (DDA) вместо физики;
собственный линейный меш для каркаса вместо wireframe-режима Godot; вся сцена и UI строятся кодом.
